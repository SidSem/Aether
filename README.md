[![GitHub](https://img.shields.io/badge/GitHub-SidSem%2FAether-181717?logo=github&logoColor=white)](https://github.com/SidSem/Aether)

A modern, high-performance web application designed for seamless travel exploration, interactive day-by-day itinerary planning, dynamic budget calculations, geospatial map navigation, and destination comparisons.

---

## 🌟 Key Highlights

- **Cinematic Discovery**: Rich hero section, category filters, and curated global destinations.
- **Interactive Trip Planner**: Day-by-day itinerary sequencing with Morning, Afternoon, and Evening activity slots.
- **Live Budget Calculator**: Instant expense breakdown across stays, transport, dining, and activities with per-person breakdowns.
- **Geospatial Map Explorer**: Interactive map markers with instant destination previews.
- **Side-by-Side Comparison**: Multi-attribute comparison engine evaluating budgets, climates, and top attractions.
- **Saved Bucket List**: LocalStorage-persisted bookmarks for easy trip retrieval.
- **Travel Journal**: Editorial travel stories and community guides.
- **Premium Micro-Interactions**: Framer Motion transitions, command palette search (`Ctrl+K`), custom preloader, and celebration confetti.
- **Dark & Light Mode**: Fluid theme switching with tailored contrast palettes.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/SidSem/Aether.git

# Navigate to project folder
cd Aether

# Install dependencies
npm install

# Run the local development server
npm run dev
```

### Build for Production
```bash
npm run build
```

- **Framework**: React 19 + Vite

- **Icons**: Lucide React
